# Changelog

All notable changes to this skill live here. Format follows
[Keep a Changelog](https://keepachangelog.com/), versioning follows semver
for the rule set.

## [0.1.0]

### Added
- Initial release: 10 rules across 4 categories, from `playbook-` guides
  through the `workflow-` plan/audit/edit loop.
- Rule bodies from the SwiftlyS2 toolkit references (provenance markers),
  reshaped to one-index-plus-rules format.
- `checks/` harness: structure validation with C# separation guard, index
  generation with `--check` mode, one-command `check.sh`, CI matrix job.
  No compiler gate by design (CS2 APIs only exist in the game server).
- README, MIT LICENSE, this changelog.
